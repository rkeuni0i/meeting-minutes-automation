# 회의록 자동화 도구

> OpenAI API로 회의 내용이 담긴 엑셀 파일을 자동 요약·정리하는 Python 도구

## 🎯 문제 정의
- 회의가 끝난 뒤 녹취 내용을 정리하는 데 시간이 많이 소요되는 문제를 해결하고자 시작
- 팀 캡스톤 프로젝트로, 반복적인 회의록 정리 작업을 자동화해 실질적인 시간 절감을 목표로 함

## 🛠 기술 스택
- **언어**: Python
- **AI 모델**: OpenAI GPT-4.1-mini API
- **라이브러리**: pandas (데이터 처리), openpyxl (엑셀 출력/스타일링)
- **선정 이유**: 정형화되지 않은 회의 텍스트를 요약하는 데는 LLM이 적합했고, 결과물을 실무에서 바로 쓰는 엑셀 형태로 내보내기 위해 openpyxl 사용

## 🏗 아키텍처
```
회의 내용 엑셀 파일 입력
      ↓
pandas로 데이터 로드 및 전처리
      ↓
OpenAI API 호출 (비정형 텍스트 → 요약)
      ↓
openpyxl로 스타일링된 엑셀 파일 출력
```

## 👤 담당 역할
- 4인 팀에서 팀 리더로 프로젝트 총괄
- 데이터 전처리 로직 및 엑셀 출력 스타일링 담당

## 🐛 트러블슈팅
- **컬럼명 불일치**: 입력 엑셀 파일마다 컬럼명이 조금씩 달라 코드가 정상 동작하지 않는 문제 발생 → 컬럼명 매핑 로직을 추가해 다양한 입력 포맷에도 대응하도록 수정
- **누락된 함수 정의**: 개발 중 일부 함수가 정의되지 않은 채 호출되는 오류 발생 → 코드 리뷰 및 테스트를 통해 누락된 로직 보완
- **비정형 텍스트 처리**: 형식이 제각각인 회의 내용을 일관되게 요약하기 위해 프롬프트를 여러 차례 조정
- **보안 이슈**: 개발 초기 API 키를 코드에 하드코딩했던 것을 발견 → 환경변수(.env)로 분리해 관리하도록 개선. 실제 서비스 배포 전 보안 취약점을 스스로 점검하고 개선한 경험

## 📈 결과 / 임팩트
- 회의록 정리 및 공유에 걸리던 시간을 **하루 → 약 3분**으로 단축 (자동화 전 대비 처리 시간 약 99% 절감)
- 반복적인 수작업 정리 과정을 제거해 팀원들이 회의 후 곧바로 결과를 공유하고 다음 액션에 착수할 수 있게 됨
